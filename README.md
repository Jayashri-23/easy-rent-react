# EasyRent 🏠

EasyRent is a simple rental property website built using React.

It allows users to explore rental properties, search and filter properties, view property details, and contact EasyRent.

## Features

- Home page
- Properties listing
- Search properties
- Filter by property type
- Filter by location
- Sort properties by price
- Property details page
- Contact Owner navigation
- About page
- Contact page with form
- Responsive design
- Reusable React components

## Technologies Used

- React
- JavaScript
- React Router
- HTML
- CSS
- Vite

## React Concepts Used

- useState
- useEffect
- useParams
- useNavigate
- NavLink
- Props
- map()
- filter()
- sort()
- Conditional Rendering
- Form Handling
- Reusable Components
